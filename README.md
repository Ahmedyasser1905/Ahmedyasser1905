## 🧑‍💻 About Me

I'm a software developer from Algeria who ships complete products — mobile apps, web platforms, AI tools, and games. My work spans the entire stack: from the React Native screen the user touches, to the NestJS API handling the request, to the Supabase database storing the result.

I've built **30+ real projects** across every category: production mobile apps published via EAS, full-stack web platforms with role-based dashboards, AI assistants integrating Gemini and OpenAI, party games with Three.js 3D scenes, and management systems with live Vercel deployments.

```text
  What defines my work
  ─────────────────────────────────────────────────────
  → I ship complete, deployed solutions — not experiments
  → I build for Arabic & multilingual users when needed
  → Mobile is a first-class platform in every project
  → AI APIs are infrastructure, not demos
  → TypeScript by default, right tool for each job
```

**Currently focused on:**
- AI-powered product development (LLM APIs, agentic systems)
- Advanced mobile architecture with React Native + Expo
- Full-stack TypeScript monorepos (NestJS + Next.js + React Native)

## 🧭 Development Philosophy

<table>
<tr>
<td width="20%" align="center"><b>🎯 Ship Complete</b></td>
<td>Every project in my portfolio has a working backend, a connected frontend, and a deployment — not a skeleton with a placeholder screen. Unfinished code teaches nothing and delivers nothing.</td>
</tr>
<tr>
<td align="center"><b>📱 Mobile First</b></td>
<td>12+ of my projects are mobile apps shipped through Expo and EAS. I treat React Native as a production platform — complete with offline-first data (SQLite), biometric auth, push notifications, and real-time sockets.</td>
</tr>
<tr>
<td align="center"><b>🌍 Build for Context</b></td>
<td>Several of my projects are built specifically for Arabic-speaking users — full RTL layouts, Arabic UI copy, culturally-appropriate design (Rawdati, SPY الجاسوس, Saifalmaraifa, Rawdhat Al-Ahlam). I don't treat internationalization as an afterthought.</td>
</tr>
<tr>
<td align="center"><b>🤖 AI as Infrastructure</b></td>
<td>I treat AI APIs (Gemini, Claude, OpenAI) as infrastructure components, not demos. Nova AI processes real documents with OCR. Brain Arena generates questions dynamically. The goal is always a usable product, not a proof of concept.</td>
</tr>
<tr>
<td align="center"><b>🏗️ Full Stack by Default</b></td>
<td>I'm not satisfied stopping at the UI. Every product I build has a database schema, an API layer, authentication, and a deployment. Whether it's a NestJS monorepo with Supabase or a PHP system with MySQL, I own the entire product.</td>
</tr>
</table>
